# SmartRetailX Project Objectives

## 1. Overall Objective

The primary objective of this project is to design and implement a secure, scalable, resilient and highly available cloud-native distributed web application for SmartRetailX using Amazon Web Services (AWS).

The proposed solution will replace the limitations of the existing monolithic architecture with independently deployable microservices, containerisation, managed cloud services and event-driven communication.

## 2. Specific Objectives

1. Design a microservices-based architecture that separates the major SmartRetailX business capabilities into loosely coupled services.

2. Develop at least three functional microservices using ASP.NET Core and RESTful APIs.

3. Containerise the microservices using Docker to provide consistent deployment environments.

4. Deploy the containerised services using Amazon ECS with AWS Fargate.

5. Implement API versioning and document the APIs using Swagger/OpenAPI.

6. Integrate Amazon API Gateway as the external entry point for the distributed services.

7. Implement cloud-managed data storage using appropriate AWS database and storage services.

8. Implement asynchronous, event-driven communication using Amazon EventBridge and Amazon SQS.

9. Use AWS Lambda for suitable serverless background-processing activities.

10. Design the architecture to support high availability through redundant infrastructure and multi-Availability-Zone deployment.

11. Design a multi-region architecture to improve resilience and support the global nature of SmartRetailX.

12. Implement appropriate security mechanisms including authentication, authorisation, secure API communication, encryption and secrets management.

13. Implement monitoring, logging and distributed tracing using AWS observability services.

14. Conduct functional, integration, performance and security testing to evaluate the system.

15. Evaluate the scalability, resilience, maintainability and cost efficiency of the proposed cloud-native architecture.
